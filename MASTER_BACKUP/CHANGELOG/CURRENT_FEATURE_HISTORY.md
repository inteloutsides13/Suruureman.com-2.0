# Current Feature History

This is a current-state index, not a replacement for Git history.

- Public Urdu poetry publishing and discovery are implemented in the web and API
  artifacts.
- Admin CRUD, analytics, settings, contact inbox, visual poetry, tools, and
  content snapshots are implemented.
- Contributor application, approval, activation, status lookup, portal, and
  deletion behavior are implemented.
- Hostinger approval-email delivery is implemented with secret-free environment
  configuration.
- Radio foundation, editorial audio library, eligibility, playlist/schedule,
  timezone, emergency, and infrastructure-preparation work is represented in the
  current schema and routes.
- The source history remains authoritative; use `git log` for commit-level detail.
